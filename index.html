⚙️ One-time Supabase setup required for PDF uploads to work on all devices:
  1. Go to your Supabase Dashboard → Storage
  2. Create a bucket named omr-pdfs (if it doesn't exist)
  3. Click the bucket → Policies → Add policy → Allow public read (for SELECT, no auth required)
  4. Also allow authenticated or anon INSERT/UPDATE — or set bucket to Public in bucket settings
  5. Once done, PDFs will persist on all devices after refresh ✓
